# Database Week 2 SQL Assignment

This project contains the SQL answers for the Week 2 assignment based on the `sales` database.

## Files included

- `about.md` — assignment instructions and questions
- `question1.sql` — retrieve payment information
- `question2.sql` — find orders in process
- `question3.sql` — list sales representatives
- `question4.sql` — retrieve all office records
- `question5.sql` — retrieve the five cheapest products
- `answers.sql` — combined SQL script with all answers

## How to use

1. Make sure the `sales` database is imported and available locally.
2. Open MySQL or your SQL client.
3. Run each query file or execute the combined `answers.sql` script.

## Assignment summary

The queries cover:
- selecting columns from a table
- filtering rows with `WHERE`
- sorting with `ORDER BY`
- limiting results with `LIMIT`
- retrieving data across tables

## Notes

All queries were written to match the assignment requirements in `about.md`.
